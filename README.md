# Mukund Ajmera — Portfolio

A lightweight, responsive portfolio built with plain HTML and CSS. It highlights selected projects from [mukundajmera on GitHub](https://github.com/mukundajmera) and links to Mukund's public LinkedIn profile.

## Preview locally

Open `index.html` in a browser, or serve this directory with any static HTTP server.

## Deploy

The site has no build step. Deploy the repository root as a static website; `index.html`, `styles.css`, and `favicon.svg` must stay together.
